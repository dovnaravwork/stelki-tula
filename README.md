# Стельки · Тула

Статический сайт Олега Ефимова с двумя отдельными направлениями:

- `/` — индивидуальные ортопедические стельки;
- `/reabilitaciya/` — физическая реабилитация и аренда Артромота.

- Сборка: `python3 build.py` → `index.html` и `reabilitaciya/index.html` (из `src/`)
- Проверка: `python3 -m unittest discover -v`
- OG-превью: `og.png` рендерится из `src/og.html`
- Хостинг: GitHub Pages
