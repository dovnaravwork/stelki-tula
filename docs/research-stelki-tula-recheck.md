## 3. SEO и локальное продвижение (Яндекс, Тула)

- **Индексация:** Яндекс индексирует *.github.io; github.io в Public Suffix List — каждый поддомен трактуется как отдельный сайт со своей репутацией. Реальная проблема — медленный краулинг молодого сайта без внешних ссылок (типовая, не специфичная для github.io). Проверку site:dovnaravwork.github.io выполнить не удалось (SmartCaptcha) — проверить вручную.
- **Яндекс.Вебмастер — нужен.** Подтверждение прав: метатег в `<head>` или HTML-файл в корне репозитория (оба работают на GitHub Pages); DNS TXT — недоступен без кастомного домена. Регион «Тула» присваивается через «География сайта → Региональность» — модератору нужны город/район обслуживания и телефон текстом на видном месте (обработка 1–2 недели). robots.txt + sitemap.xml кладутся в корень репозитория как обычные файлы.
- **Карточки — главный канал.** По запросу «ортопедические стельки Тула» в выдаче — агрегаторы и карточки (НаПоправку, 2ГИС, сайты клиник), а не визитки; ~68% кликов по локальным запросам уходит в колдунщик Карт [один источник, vc.ru 2025]. Яндекс Бизнес: бесплатная карточка по ИНН (в т.ч. самозанятому), сайт на github.io указать можно, вместо адреса — район обслуживания; карточка заодно даёт сайту регион. 2ГИС: бесплатное добавление через reklama.2gis.ru/add-info, частные мастера размещаются.
- **.ru-домен:** некритично для модели «визитка при карточках», но если сайт всерьёз — покупать сейчас, пока github.io-адрес не разошёлся по карточкам. Реальная цена: ~170–400 ₽ первый год, продление ~320–1400 ₽/год. **С 01.09.2026 регистрация/продление .ru/.рф — только с идентификацией через Госуслуги (ФЗ № 569-ФЗ от 29.12.2025)** [подтверждено вторичными источниками: Habr, webnames, sostav; первоисточник не сверялся]. Привязка к GitHub Pages штатная, старый адрес получает 301-редирект, в Вебмастере оформляется «переезд».
- **Отсутствие Метрики ранжирование не ухудшает** (официальная позиция Яндекса); ставить её стоит не ради SEO, а чтобы видеть, идут ли переходы с карточек. NB: установка счётчика меняет юридическую картину по cookie/ПДн (см. раздел 4).

**Чек-лист по приоритету:** 1) карточка Яндекс Бизнес; 2) 2ГИС; 3) Вебмастер + переобход; 4) «Тула», телефон и район обслуживания текстом на странице + schema.org LocalBusiness; 5) robots.txt + sitemap.xml; 6) внешние ссылки (карточки, профили, соцсети) и отзывы в Картах/2ГИС; 7) Метрика (по желанию, с учётом юр. последствий); 8) .ru-домен — решить сейчас.

## 4. Юридическая полнота (сайт-визитка без цен/форм/счётчиков)

### Что уже правильно
- Без форм/счётчиков/cookie: cookie-баннер не нужен, согласие на ПДн на сайте не нужно, публикация политики ПДн на сайте формально не обязательна (ч. 2 ст. 18.1 152-ФЗ привязана к сбору ПДн через ресурс). GitHub Pages с 17.12.2020 не ставит cookies на *.github.io.
- Кнопка-ссылка «написать в WhatsApp/Telegram» — не обработка ПДн на сайте.
- ЕРИР/erid не нужны: информация о собственных услугах на собственном сайте — не реклама (п. 2 ч. 2 ст. 2 38-ФЗ; письмо ФАС от 20.09.2023 № 08/76261/23).
- 236-ФЗ («приземление»), возрастная маркировка (436-ФЗ), договор-оферта — не применимы. Зарубежный хостинг для сайта без ПДн не запрещён.

### Что упущено — КРИТИЧНО
1. **Аудит формулировок.** Без медлицензии опасны: «лечение», «диагностика», «коррекция плоскостопия», обещания мед. эффекта, фото «до/после» с лечебным контекстом (п. 6 ч. 5 ст. 5 и п. 7 ст. 7 38-ФЗ; риск квалификации как безлицензионной меддеятельности — подбор стелек по мед. показаниям тяготеет к медуслуге, ПП РФ № 852). Изготовление протезно-ортопедических изделий по индивидуальным заказам само по себе НЕ лицензируется.
2. **Развилка позиционирования.** Нынешний дисклеймер «имеются противопоказания…» — атрибут рекламы медизделия и сам маркирует продукт как медицинский. Либо (а) «немедицинские индивидуальные стельки» → смягчить дисклеймер до «Не является медицинской услугой. Рекомендуется консультация врача-ортопеда»; либо (б) «медизделие/подбор по показаниям» → нужен полный мед-комплаенс (РУ Росздравнадзора или назначение врача, лицензированный партнёр). Решает владелец.
3. **Реквизиты ИП (ст. 9 ЗоЗПП)** — уже запланировано; состав: ФИО полностью, ОГРНИП, ИНН, наименование регистрирующего органа, адрес, режим работы. Для самозанятого без ИП: ЗоЗПП формально не применяется, минимальный набор — ФИО, ИНН, «плательщик НПД» [средняя уверенность — проверить статус законопроекта о ЗоЗПП для самозанятых].
4. **Уведомление РКН как оператора ПДн** — не про сайт, а про деятельность: ведение клиентов в мессенджере/смартфоне = автоматизированная обработка; исключения ст. 22 152-ФЗ с 01.09.2022 не покрывают. С 30.05.2025 — ч. 10 ст. 13.11 КоАП: для ИП до 300 тыс. ₽. Подача бесплатна.

### Желательно
- Статическая страница «Политика обработки ПДн» + внутренний документ (страховка при скринингах и на случай будущих форм/Метрики).
- Технический аудит на сторонние запросы (Google Fonts, эмбеды, карты) — чтобы «без cookie» было фактом.
- Если дисклеймер остаётся — не менее 5% площади и читаемость (ч. 7 ст. 24 38-ФЗ) — валидность при рекламном переиспользовании материалов.
- Не публиковать отзывы-«благодарности» и «случаи излечения» (п. 2, 3 ч. 1 ст. 24 38-ФЗ).
